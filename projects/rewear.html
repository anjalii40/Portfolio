Hackathon build

ReWear

ReWear was built to make clothing exchange feel structured rather than chaotic. The product allowed users to swap or redeem clothes through a points system while giving admins a moderation layer to keep the ecosystem trustworthy.

Stack

HTML, CSS, JavaScript, React.js, Node.js, Express.js, MongoDB, Cloudinary, JWT

Context

Odoo Hackathon project with a team environment and quality-focused review culture.

Product idea

The goal was to create a more sustainable fashion flow where users could exchange value without relying on direct buyer-seller transactions for every item.

Implementation

I helped build the authentication system, image upload flow, swap and redeem mechanics, and structured REST APIs that supported both users and admins.

Highlights
  • Point-based exchange system for item redemption.
  • Admin dashboard and moderation workflows.
  • Cloudinary-backed media uploads.
  • Collaborative development with structured reviews.
Takeaway

ReWear reminded me that great hackathon products still need coherence. Even under time pressure, clear API design and thoughtful user journeys make the final build feel far more complete.
