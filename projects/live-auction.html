Realtime systems

Live Auction Platform

This project explored the tension between realtime responsiveness and system fairness. The platform had to support concurrent user bids, synchronized timers, and reliable event broadcasting without compromising consistency.

Stack

React, Vite, Node.js, Express, Socket.io, Docker, Render, Vercel

Core challenge

Handle high-frequency bid events and countdown synchronization under load.

System design

I built an event-driven architecture so bids could flow through the backend as atomic updates, then fan out to clients in realtime with minimal latency.

Frontend behavior

The interface prioritized urgency and clarity with live state changes, countdown visibility, and a bidding flow that reduced hesitation at critical moments.

Highlights
  • Race-condition prevention for concurrent bids.
  • Authoritative state management for timing consistency.
  • Cloud deployment split across Render and Vercel.
  • Environment-aware configuration and secure CORS handling.
Takeaway

Realtime products need more than websockets. They need clear ownership of state, well timed broadcasts, and UI patterns that help users trust what they are seeing.
