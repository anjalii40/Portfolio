Backend + Product UI

PrimeTrade

PrimeTrade is a secure task management platform designed as a full-stack assessment build, but executed with product polish. The goal was to move beyond a basic CRUD app and create something that felt deliberate in both architecture and interface quality.

View repository Contact me
Stack

Node.js, Express, Prisma, PostgreSQL, JWT, Swagger, vanilla HTML/CSS/JS

Focus

Authentication, RBAC, secure API design, pagination, and dashboard UX.

Outcome

A deployable product with docs, admin controls, and a visually elevated frontend.

Problem

Make an assessment feel like a real product.

Most assessment dashboards stop at technical correctness. I wanted PrimeTrade to show the same level of care in user flow, visual clarity, and operational ergonomics that a product-facing engineering team would expect.

Approach

Layered architecture with strict responsibility boundaries.

The API was organized around routes, controllers, middleware, validators, and Prisma access patterns. This kept concerns separated and made auth, validation, and admin restrictions easy to reason about.

Key decisions
  • JWT auth and bcrypt-based password hashing for secure access control.
  • Role-aware admin endpoints for user review and privilege updates.
  • Swagger documentation to improve API usability and evaluator experience.
  • Paginated task browsing with status filters and clean visual grouping.
What I learned

PrimeTrade reinforced how much perceived product quality comes from the small things: response consistency, intentional copy, strong default states, and UI decisions that reduce ambiguity for users.
