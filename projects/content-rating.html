Backend architecture

Content Rating System

This project focused on recommendation logic and backend structure. I designed a rating pipeline that could classify and surface content using a six-tier progression model inspired by codex-style recommendations.

Stack

Go, PostgreSQL, Next.js, TypeScript, Recharts, Docker, Render, Vercel

Focus

Database modeling, API design, clean architecture, and reproducible deployments.

Schema

I designed a PostgreSQL schema with strong foreign key relationships, cascade deletes, and performance-minded indexes so the data layer could stay robust as recommendation queries expanded.

API shape

The backend used a clean handler → service → repository structure, which made it easier to extend business logic without turning routing code into an unmaintainable bottleneck.

Notable work
  • Six-tier progression model from newbie through grandmaster.
  • Versioned SQL schema setup for reproducible deployments.
  • RESTful endpoints with clear responsibility boundaries.
  • Frontend reporting via Next.js and Recharts.
Takeaway

Strong backend systems feel calm because the boundaries are clear. This project pushed me to think more rigorously about data shape, service contracts, and long-term maintainability.
