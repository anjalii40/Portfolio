# Anjali Prajapati Portfolio

A bold static portfolio with an editorial-tech visual style, project case studies, and a downloadable resume.

## Pages

- `index.html` for the landing page
- `projects/primetrade.html` for the PrimeTrade case study
- `projects/live-auction.html` for the Live Auction case study
- `projects/content-rating.html` for the Content Rating case study
- `projects/rewear.html` for the ReWear case study

## Stack

- HTML
- CSS
- Vanilla JavaScript

## Local preview

You can preview the site with any static file server. One simple option is:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
